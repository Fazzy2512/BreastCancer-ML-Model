# Breast Cancer Prediction Models

This repository features machine learning models designed to predict breast cancer diagnoses based on the Breast Cancer Wisconsin (Diagnostic) dataset.

## Dataset
The dataset utilized is the **Breast Cancer Wisconsin (Diagnostic)** dataset, available publicly through the [UCI Machine Learning Repository](https://archive.ics.uci.edu/ml/machine-learning-databases/breast-cancer-wisconsin/).

## Models Implemented
1. **Logistic Regression** – A logistic regression model built to predict breast cancer diagnoses.
   - The trained model is saved as `FazzyLab2_1.pkl`.

2. **Random Forest** – A random forest classifier designed for the same purpose.
   - The trained model is saved as `FazzyLab2.pkl`.
